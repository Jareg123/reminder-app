# Reminder & Notify — Возможности приложения

## Задачи

- Создание задачи с текстом (до 2 строк)
- Редактирование существующей задачи
- Удаление задачи (свайп влево + подтверждение)
- Отметить выполненным / снять отметку (тап по кружку)
- Цветная метка: 6 цветов + без метки

## Напоминания

- Напоминание с датой и временем
- Быстрые интервалы: через 1ч / 4ч / 8ч / завтра
- Кастомный интервал: дни + часы + минуты
- Выбор даты через календарь + CupertinoTimePicker
- Повторение: каждый час / каждый день / каждую неделю
- При выполнении повторяющейся задачи — автоматически переносит на следующее время
- При перезапуске приложения — перепланирует все уведомления (Android сбрасывает AlarmManager)
- Исключение из battery optimization (запрашивается при старте)

## Голосовой ввод

- Распознавание речи на русском (ru_RU)
- Автоматический парсинг дат из текста:
  - "сегодня", "завтра", "послезавтра"
  - дни недели: "в понедельник", "в следующую пятницу"
  - конкретная дата: "25 марта", "3 апреля"
  - время: "в 10", "в 10:30", "утром", "вечером", "в полдень"
  - интервалы: "через 30 минут", "через 2 часа", "через полчаса"
- Дата автоматически устанавливается в поле напоминания
- Из текста задачи убираются временны́е конструкции

## Список задач

- Сортировка: сначала невыполненные по дате, затем без даты по дате создания, выполненные в конце
- Прогресс-бар: X из Y выполнено
- Поиск по тексту задачи (с анимацией появления)
- Скрытие выполненных задач (переключатель в хедере)
- Визуальная индикация просроченных задач (оранжевый фон + иконка)
- Визуальная индикация выполненных задач (зелёный фон + зачёркнутый текст)
- Цветная полоска метки на карточке
- Иконка повторения на карточке

## Взаимодействие с карточкой

- Тап → открыть форму редактирования
- Тап по кружку → выполнено / снять отметку
- Свайп вправо → Snooze (отложить)
- Свайп влево → удалить (с подтверждением)
- Долгий тап → войти в режим мультивыбора

## Откладывание (Snooze)

- На 30 минут
- На 1 час
- На 4 часа
- До завтра
- База: от времени напоминания (или от текущего момента если нет)

## Мультивыбор

- Долгий тап на карточке → режим выбора
- Тап на карточке в режиме выбора → добавить/убрать из выбора
- Действия над группой: Готово / Перенести / Удалить
- Перенос группы: +1ч / +4ч / +1 сутки / +1 неделя / своё время
- При мультивыборе свайпы на карточках отключены

## Home Widget (Android)

- Виджет на рабочем столе — до 5 ближайших задач
- Показывает: название задачи, время напоминания, цвет метки
- Просроченные задачи выделяются оранжевым
- Обновляется при каждом изменении списка

## Интерфейс

- Тёмная и светлая тема (переключатель в хедере, сохраняется между сессиями)
- Быстрый переход в настройки уведомлений Android (иконка ноты в хедере)
- Анимированный переход на экран формы (slide + fade)
- Haptic feedback при отметке выполненным
- Пустое состояние: три режима (нет задач / всё выполнено / ничего не найдено)
- Обновление списка при возврате в приложение
