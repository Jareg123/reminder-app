# Minimal Tracker — Flutter

Приложение для отслеживания событий с пуш-уведомлениями на Android.

## Структура проекта

```
lib/
  main.dart               # UI: главный экран + экран создания/редактирования
  database.dart           # SQLite: хранение событий
  notification_service.dart  # Локальные пуш-уведомления
```

## Как запустить

### 1. Установи зависимости
```bash
flutter pub get
```

### 2. Подключи Android устройство или запусти эмулятор
```bash
flutter devices
```

### 3. Запусти приложение
```bash
flutter run
```

### 4. Собрать APK для установки
```bash
flutter build apk --release
# APK будет в: build/app/outputs/flutter-apk/app-release.apk
```

## Как работают уведомления

- Используется пакет `flutter_local_notifications` — **без Firebase**, всё локально на устройстве.
- При создании/редактировании события с напоминанием вызывается `zonedSchedule` — уведомление придёт точно в указанное время, даже если приложение закрыто.
- При удалении события уведомление отменяется автоматически.
- На Android 12+ приложение запрашивает разрешение на **точные будильники** (`SCHEDULE_EXACT_ALARM`).
- На Android 13+ запрашивается разрешение на **показ уведомлений** (`POST_NOTIFICATIONS`).

## Возможные проблемы

### Уведомление не приходит на Android 12+
Зайди в Настройки → Приложения → Minimal Tracker → Разрешения → включи **"Будильники и напоминания"**.

### Ошибка `coreLibraryDesugaring`
Убедись что в `android/app/build.gradle` есть:
```gradle
compileOptions {
    coreLibraryDesugaringEnabled true
}
dependencies {
    coreLibraryDesugaring 'com.android.tools.build:desugaring:1.2.2'
}
```
