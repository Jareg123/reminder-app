# Reminder & Notify — Flutter

Минималистичный планировщик задач с умными уведомлениями для Android. Без регистрации, без облака, всё офлайн.

---

|---|---|

| Голосовой ввод с распознаванием русских дат | ✅ |
| Напоминания: быстрые интервалы (1ч / 4ч / завтра) | ✅ |
| Напоминания: точная дата и время | ✅ |
| Повторяющиеся задачи (каждый час / день / неделю) | ✅ |
| Отложить напоминание (снуз) | ✅ |
| Свайп влево — удалить, свайп вправо — отложить | ✅ |
| Мультивыбор: выполнить / перенести / удалить | ✅ |
| Цветные метки задач | ✅ |
| Подсветка просроченных задач | ✅ |
| Скрытие выполненных задач | ✅ |

## Как работают уведомления

- Пакет `flutter_local_notifications` — без Firebase, полностью локально
- `zonedSchedule` — уведомление приходит точно в срок, даже если приложение закрыто
- Три кнопки действий прямо в шторке: выполнить, отложить на час, отложить на день
- Работают при закрытом приложении через фоновый `BroadcastReceiver`
- Android 12+ требует разрешение `SCHEDULE_EXACT_ALARM`
- Android 13+ требует разрешение `POST_NOTIFICATIONS`

## Возможные проблемы

**Уведомление не приходит на Android 12+**
Настройки → Приложения → Reminder & Notify → Разрешения → включи **«Будильники и напоминания»**

**Виджет не обновляется**
Удали виджет с рабочего стола и добавь заново — это сбрасывает кэш AppWidget.
